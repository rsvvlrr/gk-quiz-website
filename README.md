# ESCAPE — Weekend Trip Planner 🌍

ESCAPE is a modern frontend-only weekend trip planner designed to help users discover and choose destinations for a short getaway.

## ✨ Features

- 🔎 Search destinations
- 🗓️ Filter by trip duration
- 💰 Filter by budget
- ❤️ Save favorite destinations
- ✈️ Plan a weekend trip
- 🎲 Surprise Me destination
- 📖 View destination details
- 📱 Responsive design
- 💾 Favorites persist using localStorage

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
